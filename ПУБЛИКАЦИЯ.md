# Публикация: GitHub + Zenodo DOI (15 минут)

1. **GitHub**: создайте репозиторий rt2-refusal-test (public) → загрузите файлы из архива → Settings → Branches: main.
2. **Zenodo**: zenodo.org → Log in with GitHub (разрешить доступ к репозиторию).
3. В Zenodo: Create a new release для rt2-refusal-test → версия 1.0.0 → Publish. Zenodo автоматически повесит DOI на релиз.
4. DOI появится в боковой панели релиза — его вписать в CITATION.cff (строка doi:) и в раздел «Related work» статьи.
5. В описание репозитория вставить одну строку: "RT-2 — executable refusal battery (Level 2 of the Ladder of Consent). Refusals must terminate."
